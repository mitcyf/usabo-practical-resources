# Pairwise Alignment Tool Site

Static GitHub Pages site for practical resource pages and a browser-only pairwise DNA alignment tool.

## Page Structure

```text
/
|-- camp-resources/
|   `-- ibo-bioinformatics-tools/
|       `-- pairwise-alignment/
`-- plant-computation-biology/
```

The alignment tool lives at:

```text
/camp-resources/ibo-bioinformatics-tools/pairwise-alignment/
```

## Deploy on GitHub Pages

1. Create a new public GitHub repository, for example `usabo-practical-resources`.
2. Put these files at the repository root.
3. Commit and push to the `main` branch.
4. In GitHub, open the repository settings.
5. Go to Pages.
6. Set the source to deploy from a branch.
7. Choose `main` and `/ (root)`.

The site will be available at:

```text
https://YOUR_USERNAME.github.io/usabo-practical-resources/
```

GitHub Pages can take a few minutes to publish after the first push.
