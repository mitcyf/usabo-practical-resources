IBO Practical Tools

Browser-based tools for the computational parts of the practical workflow.

Bioinformatics

  • Notepad Use a temporary scratchpad during the practical workflow.
  • Codon Alignment Project a protein CLUSTAL alignment onto matching coding DNA sequences.
  • DNA to Protein Translate a DNA FASTA sequence with Biopython translation behavior.
  • ORF Finder Find candidate open reading frames using Biopython genetic-code tables.
  • Restriction Mapper Search Biopython's restriction enzyme library for cut sites.
  • Reverse Complement Generate the reverse complement of a DNA sequence.
  • Sequence Editor Edit, translate, and inspect DNA with linked codon and amino acid selection.
  • Sequence Alignment Align two or more FASTA sequences in the browser while Clustal Omega options are evaluated.
  • Tm Calculator Calculate DNA melting temperature using Biopython nearest-neighbor defaults.
  • Tree Builder Build a Biopython neighbor-joining tree from an alignment.
