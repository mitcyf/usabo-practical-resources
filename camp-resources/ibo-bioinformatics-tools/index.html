IBO Bioinformatics Tools

Browser-based tools for practical bioinformatics workflows.

Tools

  • ORF Finder Find candidate open reading frames and translate coding sequences.
  • Restriction Mapper Locate common restriction enzyme recognition sites and cut positions.
  • Sequence Editor Edit, translate, and inspect DNA with linked codon and amino acid selection.
  • Sequence Alignment Align two or more DNA or protein FASTA sequences in the browser.
  • Tree Builder Build a simple UPGMA tree from an aligned FASTA input.
